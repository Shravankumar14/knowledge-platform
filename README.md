# Knowledge Sharing Platform (MERN Stack)

A full-stack course platform where instructors create courses and students enroll — built with MongoDB, Express, React, and Node.js.

## Live Demo
- Frontend: https://your-vercel-url.vercel.app
- Backend API: https://knowledge-platform-qku0.onrender.com/api/health

## Features
- JWT authentication with role-based access (student/instructor)
- Instructors can create courses
- Students can browse and enroll in courses
- Protected REST API routes with middleware

## Tech Stack
- **Frontend:** React, React Router, Axios, Vite
- **Backend:** Node.js, Express, MongoDB (Mongoose), JWT, bcrypt
- **Deployment:** Vercel (frontend), Render (backend), MongoDB Atlas

## Note
Backend is on Render's free tier — first request after idle may take 30-50s to wake up.
